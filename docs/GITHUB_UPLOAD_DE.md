# GitHub-Upload

1. Erstelle ein leeres Repository `OpenADAS-Vision-Stack`.
2. Führe im Projektordner aus:

```powershell
git init
git add .
git commit -m "Initial commit: OpenADAS vision and safety pipeline"
git branch -M main
git remote add origin https://github.com/hosseinAT/OpenADAS-Vision-Stack.git
git push -u origin main
```
